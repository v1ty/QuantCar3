# Quarter-Car Suspension Modeling and Simulation

## Project Summary

This project develops a quarter-car suspension model using MATLAB,
Simulink, Simscape, and Simscape Multibody.

The model represents one vehicle corner using:

- Sprung mass
- Unsprung mass
- Suspension spring
- Suspension damper
- Tire compliance
- Road displacement input

The suspension will be tested using multiple road profiles. Performance
will be measured using ride comfort, suspension travel, and tire
deflection metrics.

## Project Goals

1. Create a team agreement and guidelines that are expected to be followed for the project
2. Build a working quarter-car suspension model.
3. Simulate several road disturbances and create a test for our model
4. Test various tradeoffs and make an executive decision on the best suspension system for various conditions. 
5. Learn how to collaborate with a team of diverse skills
6. Work in a remote environment with communication relying on discord, email, and weekly meetings

## Team Roles

- Project Manager (PM): Schedules meetings; maintains timeline; ensures tasks are tracked and disagreements are resolved.
- Modeling Lead: Owns core MATLAB models/simulations
- Analysis/Validation Lead: Performs hand calculations and cross-checks simulation outputs 
- Documentation & Visualization Lead: Compiles report (with figures/tables), prepares slides (if needed), and builds visual artifacts (e.g. animations or plots)

## How to Run

1. Download or clone the project files.
2. Open the MATLAB project file.
3. Open the main Live Script and Simulink model.
4. Run the setup sections by clicking on the "Run" button.
5. The simulation will execute the selected road profile and generate data for the suspension system.

## Challenges 

None of the members had experience with MATLAB simulation setting and had to learn through lectures online. Members were more familiar with the coding and script aspect of it.
There were various steps that were simplified like the simulation model and road cases, giving a rough visualization of a quarter car rather than a precise representation. 

There was difficulty in understanding the exact steps or measures required to take in order to start the project. Small tasks which were listed were attempted first, then more plots, detailing, and visuals were added. 

## Personal Experiences
Discussion among team members took place along the project. Videos from and about MATLAB were watched to learn new skills. Past familiar experiences with coding were put to test. Physics based theory was applied when dealing with a spring mass system. Teamwork and communication rose above all, being the strongest suite in this project.
